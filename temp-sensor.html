Temperature Sensor Minor Project

Experimented with temperature sensors by connecting them to an Arduino Nano and bringing the data to life through Python software. I built real-time monitoring and visualization scripts that turned raw environmental readings into clear, dynamic insights, making the process feel less like coding and more like watching the environment tell its own story.
